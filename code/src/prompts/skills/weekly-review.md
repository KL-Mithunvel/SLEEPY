# Weekly Review Skill

## Step 1 — Review the Week

1. Read this week's daily logs (`logs/YYYY-MM-DD.md` for each day).
2. List all tasks marked `[x]` (completed) across all project files that were updated this week.
3. List all tasks still `[ ]` (unchecked) that are overdue.
4. Ask the user: any wins, blockers, or things to note from this week?

## Step 2 — Project Health Check

For each active project:
1. Read the project file.
2. Note: last activity date, number of open tasks, any blocked or overdue items.
3. Flag any project with no activity in 14+ days as "at risk".

## Step 3 — Plan Next Week

1. Read the Plans file for next week (`Plans/YYYY/WNN/YYYY-MM-DD.md`) or create it.
2. From overdue tasks and upcoming `due:` dates, suggest the top 5 items for next week.
3. Ask user to confirm and adjust the list.
4. Write the confirmed plan to the Plans file.

## Step 4 — Weekly Log

Create or update `logs/YYYY-WNN.md` with:
- Completed highlights
- Blockers and risks
- Next week's plan summary
- Any people/delegation notes
