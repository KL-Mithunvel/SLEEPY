# Meeting Prep Skill

## Steps

1. Ask: who is the meeting with, what is the topic, and when?
2. Search People.md for the attendees — surface any notes on working style or recent interactions.
3. Search the corpus for relevant project files, open tasks, and recent decisions related to the topic.
4. Draft a meeting prep note:

```markdown
## Meeting: <Title> — <Date> <Time>

### Attendees
- <name> (<role>)

### Agenda
1. <item>
2. <item>

### Open Items to Resolve
- [ ] <question or decision needed>

### Context
<2-3 bullet points from the corpus>

### Follow-up Owners
- <name>: <action>
```

5. Ask if the user wants to save this prep note to the relevant project file or a daily log.
